# Repository and submission checklist

This checklist implements the repository requirements supplied by the participant from the challenge announcement. The [official public announcement](https://blog.jetbrains.com/education/2026/10/12/build-your-game-challenge-join-in-and-compete-for-prizes/) directs entrants to Discord for the full current rules. Check the organizer's wording in Discord before submitting; this file is not a legal or eligibility certification.

## Repository requirements

- [x] Public GitHub repository created and verified: https://github.com/ajeetpratapsingh12/spirit-sanctuary
- [x] Public playable GitHub Pages URL deployed and verified: https://ajeetpratapsingh12.github.io/spirit-sanctuary/
- [x] Source and all runtime assets included. No private services, API keys or downloaded packages are required to run.
- [x] Build/run commands in README.md; deterministic offline/static packaging in build.mjs.
- [x] Course attribution in README.md, NOTICE and ATTRIBUTION.md; original MIT license retained in LICENSE.
- [x] Third-party software/assets with source and license terms in ASSETS.md; dependency licenses included.
- [x] OpenAI Codex and image-generation use disclosed in AI_DISCLOSURE.md, including which parts they produced.
- [x] Original extension models/scenery and procedural audio; no reference screenshots, commercial recordings, recognizable third-party characters, logos or memes included in the prepared package.
- [x] Short extension description kept under 500 characters in SUBMISSION.md.
- [ ] Participant keeps the repository public until at least October 30, 2026. This is an ongoing obligation, not something a one-time upload can guarantee.

## Required participant materials

- [ ] Genuine course-completion certificate from the IDE, with the participant signed into the proper JetBrains account during completion.
- [ ] Gameplay video/GIF of the final game, at most 20 seconds and 20 MB.
- [ ] Participant's personal review and acceptance of the challenge terms in the bot.
- [ ] Review of any earlier prototype authorship/assets/tools not recorded in this revision history.

No certificate is fabricated. No course completion, terms acceptance, voting or contest submission is performed by the repository tooling.
