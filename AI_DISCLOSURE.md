# AI tools and contributions

This project was developed with AI assistance under the participant's direction.

| Tool | Contribution |
| --- | --- |
| **OpenAI Codex** | Inspected and revised the supplied browser prototype; generated/edited movement and touch controls, camera framing, procedural character/creature models and animation, combat effects, ascension, boss cinematics and willow rebirth, garden scenery, HUD/menu, graphics/performance work, synthesized sound, offline packaging, repository scripts and documentation. The participant supplied the starting HTML prototype, creative direction and visual reference screenshots, selected improvements and reviewed development. AI tools used before the supplied prototype are unknown to this revision history; the participant must add them if applicable. This disclosure does not claim that Junie, Junie Lite or JetBrains Air was used when that has not been established.

## Generated texture direction

The texture prompt requested an original seamless, straight-down ink-and-gouache fantasy garden paving texture: irregular broken blue-teal slate, fine dark cracks, worn edges, forest moss, tiny clover and pale petals, even illumination, with no characters, text, logos, UI or circular markings. Its source was an image-generation output, not a texture downloaded from another game.

## Other tooling

Three.js renders the scene, precompiled Tailwind CSS supplies UI utilities, and Web Audio synthesizes the sound. These are software dependencies, not additional AI authors. Earlier recording/editing work in the development session used FFmpeg with Codex assistance; an old video is not included as a representation of the final build in this repository.

The extension's code and artwork should not be described as entirely human-authored or as made without AI. The participant remains responsible for the submission, prior attribution, course completion, final review and acceptance of the challenge terms.
